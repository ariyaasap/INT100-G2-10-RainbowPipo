# 📜Test Script
**Part 1 : แนะนำตัว**
- สวัสดีครับพวกผมมาจากมจธเคยมาสอบถามเกี่ยวกับตลาดนี้ในเรื่องปัญหาต่างๆของพ่อค้าแม่ค้า ครั้งนี้เลยจะมาเสนอตันต้นแบบครั้งนี้ และตัวงานนี้เป็นแค่งานส่งอาจารย์ไม่ได้จะนำมาใช้จริงเพื่อการนั้นแล้วเลยอยากจะได้รับความเห็นเพื่อจะนำไปปรับปรุงครับ

**Part 2 : เกริ่นนำ**
- เราทำprototype ความต้องการของเรา ทำให้ร้านมีชื่อเสียงเป็นที่รู้จักเพื่อกระตุ้นยอดขายและเศรษฐกิจ

**Part 3 : แนะนำแอป**
- โดยหลักการทำงานจะเป็นให้ผู้ใช้บริการตลาดสะสมแสตมป์เพื่อแลกส่วนลดกับทางร้านค้าโดยเงื่อนไขการได้แสตป์จะเป็นการทำภารกิจ เช่น การถ่ายวิดีโอโปรโมทร้านค้า การซื้อของตามราคาที่กำหนดเป็นต้น 

**Part 4 : ถามความเห็น**
- พวกอยากทราบความเห็นของคุณว่า คิดว่าตัวต้นแบบของเรา เป็นอย่างไร มีแค่แนะนำหรือ ข้อคิดเห็นใดเกี่ยวกับผลงานนี้บ้าง

**Part 5 : ปิดท้าย**
- ขอบคุณคุณป้า/ลุง ที่สละเวลามาให้ความคิดเห็นกับพวกเรา พวกเราจะนำ feedback กลับไปปรับปรุงพัฒนาผลงานต่อไป ขอบคุณครับ
