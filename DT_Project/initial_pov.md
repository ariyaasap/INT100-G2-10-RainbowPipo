# Initial POV Statement

**[User - ผู้ใช้งาน] + [Need - ความต้องการที่จำเป็น] + [Insight - ข้อมูลเชิงลึก/เหตุผลที่ค้นพบ]**

**User** : กลุ่มพ่อค้าแม่ค้าอาวุโสในตลาด

**Need** : ต้องการวิธีการบริหารจัดการหน้าร้านและการเข้าถึงของลูกค้าให้มีประสิทธิภาพมากขึ้น เพื่อสร้างรายได้ที่มั่นคงโดยไม่ต้องพึ่งพาสภาพอากาศหรือนโยบายรัฐเพียงอย่างเดียว

**Insight** : เพราะพฤติกรรมของลูกค้าเปลี่ยนไปเน้นเรื่องความสะดวกสบายมากขึ้น (เช่น ต้องการที่จอดรถ หรือสั่งออนไลน์ในวันฝนตก) ในขณะที่ผู้ค้าส่วนใหญ่ยังติดข้อจำกัดด้านกายภาพของตลาด และคุ้นเคยกับการตั้งรับมากกว่าการปรับตัวเข้าสู่ระบบแพลตฟอร์มสมัยใหม่
