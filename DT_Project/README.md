## 📌 Project Overview (ภาพรวมโครงการ)
โครงการนี้เป็นส่วนหนึ่งของวิชา **INT100 IT Fundamentals** ที่ประยุกต์ใช้กระบวนการ **Design Thinking** ในขั้นตอน **Empathize** และ **Define** เพื่อค้นหาและทำความเข้าใจปัญหาเชิงลึก (Insights), ความต้องการ (Needs), และพฤติกรรมของกลุ่มพ่อค้าแม่ค้าอาวุโสในตลาดสด/ตลาดนัด ซึ่งได้รับผลกระทบจากปัจจัยภายนอก เช่น สภาพอากาศ โครงสร้างพื้นฐานตลาด และนโยบายกระตุ้นเศรษฐกิจจากภาครัฐ

---

## 📍 Target Location (สถานที่เป้าหมาย)
* **สถานที่ที่ลงพื้นที่:** ตลาด 61 (ตลาดใหม่ทุ่งครุ ประชาอุทิศ 61)
* **ลักษณะบริบทพื้นที่:** เป็นตลาดขนาดใหญ่ในย่านชุมชนใกล้มหาวิทยาลัยมจธ.และแหล่งที่พักอาศัย มีทั้งโซนตลาดสด ตลาดนัด และร้านอาหาร 
* **กลุ่มเป้าหมายที่สัมภาษณ์:** พ่อค้าแม่ค้าที่ประกอบอาชีพในพื้นที่ตลาด 61 จำนวน 5 ร้านค้า

---

## 🔍 Key Findings & Insights (สรุปผลการสอบถามเบื้องต้น)

###  5 ร้านค้ากรณีศึกษา (5 Market Vendors Case Studies)
* **ร้านขนมไทย:** ย้ายตลาดเพราะปัญหาที่จอดรถ ยอดขายขึ้นอยู่กับโครงการกระตุ้นเศรษฐกิจ (ไทยช่วยไทย) ยอดขายน้อยลงเมื่อหมดโครงการ
* **ร้านใหญ่ที่คุมพื้นที่ด้านหลังตลาด:** ปรับตัวโดยมีการบริการ **Delivery** เพื่อแก้ปัญหาลูกค้าไม่เดินตลาดในวันที่ฝนตกและสู้กับการแข่งขันจากร้านสะดวกซื้อ (7-Eleven)
* **ร้านลุงขายเนื้อสด:** ประสบปัญหาการขนย้ายวัตถุดิบหรือของที่จะขายเข้าพื้นที่ช่วงเช้าเนื่องจากทำเลอยู่กลางตลาด ยอดขายพีคเฉพาะช่วงต้น/ปลายเดือน
* **ร้านหมาล่า:** ยอมไม่ปรับราคาขายเดิมเพื่อรักษาฐานลูกค้านักเรียน/คนงาน แม้ต้นทุนวัตถุดิบจะสูงขึ้น ต้องรับภาระแบกรับของเหลือในวันฝนตก
* **ร้านทาโกะยากิ:** ปรับเวลาขายเป็นช่วงเย็นเพื่อเลี่ยงแดดร้อน ปัญหาร่มกันแดดและขยะในตลาด
