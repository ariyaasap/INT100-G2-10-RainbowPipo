**Topic:** Market Vendors' Pain Points & User Experience in Local Markets

## 📌 Project Overview (ภาพรวมโครงการ)
โครงการนี้เป็นส่วนหนึ่งของวิชา **INT100 IT Fundamentals** ที่ประยุกต์ใช้กระบวนการ **Design Thinking** ในขั้นตอน **Empathize** และ **Define** เพื่อค้นหาและทำความเข้าใจปัญหาเชิงลึก (Insights), ความต้องการ (Needs), และพฤติกรรมของกลุ่มพ่อค้าแม่ค้าอาวุโสในตลาดสด/ตลาดนัด ซึ่งได้รับผลกระทบจากปัจจัยภายนอก เช่น สภาพอากาศ โครงสร้างพื้นฐานตลาด และนโยบายกระตุ้นเศรษฐกิจจากภาครัฐ

## 🔍 Key Findings & Insights (สรุปผลการศึกษาเบื้องต้น)

### 1. 5 ร้านค้ากรณีศึกษา (5 Market Vendors Case Studies)
* **ร้านขนมไทย:** ย้ายตลาดเพราะปัญหาที่จอดรถ ยอดขายขึ้นอยู่กับโครงการกระตุ้นเศรษฐกิจ (ไทยช่วยไทย) ยอดขายน้อยลงเมื่อหมดโครงการ
* **ร้านใหญ่ที่คุมพื้นที่ด้านหลังตลาด:** ปรับตัวโดยมีการบริการ **Delivery** เพื่อแก้ปัญหาลูกค้าไม่เดินตลาดในวันที่ฝนตกและสู้กับการแข่งขันจากร้านสะดวกซื้อ (7-Eleven)
* **ร้านลุงขายเนื้อสด:** ประสบปัญหาการขนย้ายวัตถุดิบหรือของที่จะขายเข้าพื้นที่ช่วงเช้าเนื่องจากทำเลอยู่กลางตลาด ยอดขายพีคเฉพาะช่วงต้น/ปลายเดือน
* **ร้าน Dog Hunt:** ยอมไม่ปรับราคาขายเดิมเพื่อรักษาฐานลูกค้านักเรียน/คนงาน แม้ต้นทุนวัตถุดิบจะสูงขึ้น ต้องรับภาระแบกรับของเหลือในวันฝนตก
* **ร้านทาโกะยากิ:** ปรับเวลาขายเป็นช่วงเย็นเพื่อเลี่ยงแดดร้อน ปัญหาร่มกันแดดและขยะในตลาด

### 2. User Persona Summary ("คุณสมใจ")
* **Profile:** ผู้ค้าอาวุโส อายุเฉลี่ย 60 ปี ทำงานตั้งแต่เช้าตรู่ถึงเย็น
* **Main Pain Points:** 
  1. ยอดขายแกว่ง ขึ้นอยู่กับโครงการรัฐบาล
  2. ปัญหาที่จอดรถน้อย ทำให้ลูกค้าหนีไปที่อื่น
  3. สภาพอากาศ (ฝนตก/แดดร้อน) ทำให้ตลาดเงียบเหงา
* **Adaptation:** ปรับตัวแบบตั้งรับ (Reactive) บางส่วนเริ่มหันมาใช้แอปพลิเคชัน Delivery และสังคมไร้เงินสด

## 🎯 Initial POV Statement (กรอบคำถามเพื่อการออกแบบ)
> **กลุ่มผู้ใช้:** กลุ่มพ่อค้าแม่ค้าอาวุโสในตลาดที่ยอดขายผันผวนตามปัจจัยภายนอกและความสะดวกของพื้นที่  
> **ต้องการวิธี:** บริหารจัดการหน้าร้านและการเข้าถึงของลูกค้าให้มีประสิทธิภาพมากขึ้น เพื่อสร้างรายได้ที่มั่นคงโดยไม่ต้องพึ่งพาสภาพอากาศหรือนโยบายรัฐเพียงอย่างเดียว  
> **เพราะว่า:** พฤติกรรมลูกค้าเปลี่ยนไปรักความสะดวกสบาย ในขณะที่ผู้ค้ายังติดข้อจำกัดด้านกายภาพของตลาด และคุ้นเคยกับการตั้งรับมากกว่าการปรับตัวเข้าสู่แพลตฟอร์มสมัยใหม่
