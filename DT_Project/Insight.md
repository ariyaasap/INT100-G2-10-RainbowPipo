# 💡Identified insights

**พ่อค้าแม่ค้าอยากให้ลูกค้ามาซื้อข้าวของที่ตลาดเพิ่มขึ้น**
- ส่วนใหญ่มองว่าตลาดมีที่จอดรถน้อย ส่งผลให้ลูกค้ามาที่ตลาดน้อยลง ตลาดเงียบเหงา คนไม่ค่อยมาเที่ยวตลาด

**พ่อค้าแม่ค้าต้องการปรับรูปแบบการขายให้หลากหลายขึ้น**
- เนื่องจากปัจจุบัน พฤติกรรมของลูกค้าเปลื่ยนไป จึงรู้สึกต้องการวิธีการค้าขายของที่มากกว่าการขายที่หน้าร้าน เพื่อตอบสนองความต้องการของลูกค้า

**พ่อค้าแม่ค้าต้องการสิ่งกระตุ้นในการใช้จ่ายของลูกค้า**
- พ่อค้าแม่ค้าแทบทุกคนมองว่า นโยบายกระตุ้นเศรษฐกิจของรัฐบาล มีผลต่อการใช้จ่ายซื้อของของลูกค้ามาก เมื่อไม่มีจะทำให้บรรยากาศเงียบเหงาซบเซา คนไม่มาซื้อของกัน
